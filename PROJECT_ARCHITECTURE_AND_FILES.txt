1. EXECUTIVE OVERVIEW & ARCHITECTURE
================================================================================
DeepTrace is an open-access, high-performance tactical web platform designed for
autonomous sub-surface acoustic reconnaissance, ghost gear detection (YOLOv11x),
bathymetric cartography, and marine habitat conservation.

The system is built as a 2-Page Responsive Web Application:
- Page 1: Standalone Home & Authentication Gateway (Sonar Logo on Center-Left &
  Tactical Login / Guest Portal on Center-Right with dynamic Roll Text effects).
- Page 2: Tactical Command Dashboard featuring the 11-step neural acoustic
  pipeline, Hero Telemetry Gauges, Sticky Stepper, Fixed Vertical Nav Rail,
  Full-Journey Skiper19 Sonar Scout Fish, Launch CTA, and the 6-crew Dossier Team
  section with organic tilt and hover alignment.

3. APPLICATION & TECHNICAL ARCHITECTURE
================================================================================

A. TWO-PAGE GATEWAY ARCHITECTURE:
---------------------------------
The application uses a state-driven 2-page flow governed by `hasEntered`:
1. `hasEntered = false` (Page 1 - Home Gateway):
   - Renders `HomeAuthSection.tsx`.
   - Center-Left: DeepTrace 360° holographic radar emblem with scan beam.
   - Center-Right: Tactical Login Box with password toggle and error validation.
   - Dynamic Roll Text: "DEEPTRACE" letter-by-letter 3D roll and cycling mission
     word pill ("GHOST GEAR DETECTION", "MARINE CONSERVATION", etc.).
   - Login Credentials: Crew members authenticate with their exact credentials
     (e.g., username "monish iyyappan", password "monish@iyyappan"), which sets
     `signedInMemberId` and flags that teammate as ACTIVE.
   - Guest Access: Non-teammates can click "ENTER WITHOUT CREDENTIALS (NON-TEAMMATES)"
     to explore the application with full read access.

2. `hasEntered = true` (Page 2 - Tactical Platform):
   - Renders Header, Stepper, Vertical Rail, Hero, 11 Pipeline Stages,
     Launch Box CTA, Team Dossier Section, and Footer.
   - Clicking the Top-Left Header Logo returns the user to Page 1.

B. SESSION & ACTIVE/UNACTIVE LIFECYCLE:
--------------------------------------
- All team members initialize as UNACTIVE by default.
- Only the currently signed-in teammate displays the glowing cyan "ACTIVE" badge.
- When the user exits the browser or reloads the tab, a `beforeunload` listener
  automatically purges the session, resetting all members to "UNACTIVE".

C. MOTION & ANIMATION ENGINE (Lenis + GSAP + Framer Motion):
------------------------------------------------------------
- Smooth Kinetic Scroll: Powered by Lenis, synchronized with GSAP ticker.
- Cursor Spotlight: Hardware-accelerated CSS custom property (`--mouse-x`, `--mouse-y`)
  producing a radial glow border following the cursor on all cards.
- Magnetic Physics: Buttons gently pull toward the cursor using elastic GSAP tweens.
- Skiper17 Rotational GSAP Sequence:
  Each section enters with a dynamic GSAP ScrollTrigger rotation and aligns straight
  to 0° on hover:
  * Logo & Header: Entrance rotation from -18° to 0°.
  * Optical Radar: Entrance rotation from -12° to 0° with magnetic tilt.
  * Image Preview (Skiper48): Subtle resting tilt (-1.5°) straightening to 0° on hover.
  * Step Cards (01 to 11): Alternating resting tilt angles ([-1.8°, 1.8°, -1.5°, 1.5°...])
    with GSAP ScrollTrigger entrance, snapping to 0° on hover.
  * Launch Box CTA: Enters with rotation -4.5° -> -1.5°, straightening to 0° on hover.
  * Teammates Section: Alternating dossier resting angles ([-4.5°, 3.5°, -3.5°, 3.5°, -2.5°, 3.5°]),
    smoothly snapping to 0° on hover with spring return.

D. SKIPER19 FULL-JOURNEY CYBERNETIC SONAR SCOUT FISH:
-----------------------------------------------------
- Full-page swimming scout drone that originates at the DeepTrace logo at the top
  and swims smoothly down the left track alongside content to the end of the page.
- Animated SVG body with flapping pectoral fins, oscillating tail fin with glowing
  core, pulsating optic visor, sonar ping waves, and trailing bubble wake.
- Real-time HUD readout calculating dynamic sub-sea depth (-0040M to -4200M) and
  active milestone tracking (GATEWAY -> RADAR -> NEURAL -> MAPPING -> LAUNCH -> TEAM).

4. COMPLETE FILE-BY-FILE BREAKDOWN
================================================================================

--- [ROOT CONFIGURATION FILES] ---

1. `index.html`:
   The root HTML document. Contains the tactical viewport settings, Orbitron /
   Space Mono / Oxanium font links, Google Material Symbols icon sheets, CRT
   scanline overlays, and the root `<div id="root"></div>` mounting point.

2. `package.json`:
   Node.js package manifest. Declares dependencies including `react`, `react-dom`,
   `gsap`, `framer-motion`, `lenis`, `lucide-react`, `tailwind-merge`, and
   devDependencies (`vite`, `@vitejs/plugin-react`, `typescript`).

3. `tsconfig.json`:
   TypeScript compiler configuration enabling strict mode, JSX React-JSX transform,
   ESNext module resolution, and module bundling.

4. `vite.config.ts`:
   Vite build and dev-server configuration with `@vitejs/plugin-react` plugin.

5. `vercel.json`:
   Production deployment configuration for Vercel. Includes SPA client-side route
   rewrites (`/(.*) -> /index.html`), 1-year immutable caching for `/assets/*`, and
   security headers (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection).

6. `README.md`:
   Repository markdown documentation with project description, cloning instructions,
   scripts, and pipeline overview.

7. `PROJECT_ARCHITECTURE_AND_FILES.txt`:
   This master architectural document and file guide.

--- [SRC ROOT FILES] ---

8. `src/main.tsx`:
   Application bootstrapping file. Renders `<App />` into the DOM `root` element
   inside React `StrictMode`.

9. `src/index.css`:
   Global CSS styling file. Configures custom dark theme variables, tactical
   scrollbars, Orbitron/Oxanium font rules, CRT scanline overlay, spotlight card
   borders, and keyframe animations (`fish-tail-swim`, `fish-fin-flutter`,
   `fish-sonar-ping`, `radar-sweep`, `sonar-blip`).

10. `src/vanilla-stepper.ts`:
    TypeScript helper module managing session lifecycle and beforeunload event
    listeners ensuring credentials reset to UNACTIVE upon browser reload/exit.

--- [DATA, TYPES, UTILS & LIB] ---

11. `src/types/index.ts`:

    - `MissionMetric`: Telemetry key, value, label, trend.
    - `LightboxImage`: Image URL, alt text, caption, bounding rectangle.

12. `src/data/pipelineData.ts`:
    Master data store containing:
    - `PIPELINE_STAGES`: 11 stages covering Raw Hydrophone Ingestion, Slant-Range
      Correction, Adaptive Beamforming, YOLOv11x Ghost Gear Detection, Bathymetric
      Mapping, Bio-Entanglement Risk Assessment, and Fleet Georeferencing.

      2. SAI JAIWANT (sai jaiwant / sai@jaiwant)
      3. MONISHA MURUGAN (monisha murugan / monisha@murugan)
      4. MONISHA SATHISH (monisha sathish / monisha@sathish)
      5. MANISHA V (manisha v / manisha@v)
      6. MONISHA VENKATESAN (monisha venkatesan / monisha@venkatesan)
    - `MISSION_METRICS`: Real-time system telemetry benchmark specifications.

13. `src/lib/utils.ts`:
    Helper function `cn()` combining `clsx` and `tailwind-merge` for clean,
    conflict-free dynamic Tailwind class strings.

14. `src/utils/motion.ts`:
    Motion and physics engine utilities:
    - `initSmoothScroll()`: Initializes Lenis kinetic scroll tied to GSAP ticker.
    - `scrollToTarget()`: Smoothly scrolls to target element/ID with Lenis offset.
    - `attachMagneticEffect()`: Attaches elastic magnetic cursor attraction.
    - `attachSpotlight()`: Computes mouse coordinates for radial neon border glow.
    - `attachCardTilt()`: 3D cursor-following tilt effect.
    - `isReducedMotion()`: Checks system accessibility preferences.

6. BUILD, RUN & DEPLOYMENT GUIDE
================================================================================

A. LOCAL DEVELOPMENT:
   Run the Vite development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

B. PRODUCTION BUILD:
   Compile TypeScript and build optimized assets:
   ```bash
   npm run build
   ```
   Output is generated in the `dist/` directory.

C. PREVIEW PRODUCTION BUILD:
   ```bash
   npm run preview
   ```

D. DEPLOYING TO VERCEL:
   Method 1 (Git): Push your repository to GitHub; import into Vercel.
   Method 2 (CLI): Run `npx vercel` in the project root.
   Vercel reads `vercel.json` and automatically sets up SPA rewrites and caching.
